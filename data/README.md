# Data

Curated CSV files from the campaign (public Kaggle dataset `lucasrangelss/gpu-ai-benchmark-campaign-2026`). One row per measured run or attempt; the columns are described in the dataset page. Host locations and instance identifiers were removed.

- `supra_attempts.csv`: the ten attempts: stage reached, cause class, wall time, session rental cost
- `supra_completed_runs.csv`: stage timings and quality line of the two finished runs
- `viewer_local_check.csv`: build record of the open 3D room viewer on a local machine
